01 / What it does

A reproducible lab for real inference decisions.

01

Hugging Face serving

Loads local or remote causal LLMs with batched generation and a tiny CPU-friendly default.

02

Serving metrics

Captures tokens/sec, p50/p90/p99 per-token latency, warmups, batch size, and raw run samples.

03

GPU comparisons

Compare fp32, fp16, and int8 across model sizes and observe peak CUDA memory.

02 / Why this needs GPU

Inference is memory movement, kernel efficiency, and tail latency.

Generative serving repeatedly reads weights and caches state while executing tensor kernels. GPU memory bandwidth and tensor-core throughput can dominate both throughput and the p99 latency that users experience.

Model scaleWeight footprint and KV-cache pressurePrecisionfp16 and int8 speed/memory tradeoffsBatch shapeGPU utilization and queueing behavior

03 / Quickstart

From clone to benchmark.

# CPU-safe verification
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python inference/benchmark.py --device cpu
# Nebius GPU instance
./run.sh --model <hf-model-id> \
  --model-size 7B \
  --quantization fp16 \
  --device cuda \
  --batch-size 8
